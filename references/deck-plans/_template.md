# 牌组打法模板

## 构筑

```text
# 在这里贴入本次使用的完整 50 张牌表，每行写「张数 官方卡号」。
```

成文时保留「构筑」为第一章，用实际牌表替换上面的提示，保留每个官方卡号的完整后缀。可在牌表的 `#` 注释行注明预组 ID 或自组牌表来源。每次使用本打法前，与本局牌表逐卡核对。两边卡号及各自张数全部相同才可使用。

文档标题用牌组名和核心打法。以下阶段名可以按这副牌的实际联动时点改写。

## 赢法与关键牌

用一段话说明怎样获得手牌或场面优势、最终靠什么赢。给核心角色和对应潮标上卡号、张数，写清检索、回收或变身所需的来源区。算替代件时说明它在什么条件下才算多一张可用的联动人。

## 换牌与开局

给一个具体起手，说明留谁、换谁、第一笔检索找谁。写出缺攻击手或已有联动人但缺潮时，留牌顺序怎样改变。

## 各级运营与转向

写明每次升级怎样选颜色，每个联动回合需要怎样布场，发动后优先取哪张牌。靠待机压场的构筑，写清提前送进休息室的目标、落点和下回合能否攻击。把一次关键回合的手牌净变化和库存支出算清楚，再说明何时适合改变原计划。

## 终盘与攻击顺序

列出斩杀的前置任务、登场费、每次发动费和弃牌数。用一种能凑齐的场面说明应该先打哪列、打几包伤害。结合对手的等级、时计及可见潮数，给出缺件或面对不同压缩时可执行的备选线。
